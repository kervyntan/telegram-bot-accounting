# Assets Directory

## Logo Setup

To use your JaxTrades logo in the PDF invoices:

1. Save your logo image as `logo.jpg` in this directory
2. The PDF generator will automatically use it in place of the business name text
3. Supported formats: JPG, PNG (save as `logo.jpg` or `logo.png`)

The logo will be displayed at approximately 40mm x 20mm in the PDF header.
If the logo file is not found, the system will fall back to displaying the business name as text.
